                    사용자 매뉴얼 (시트별 안내)
================================================================================

이 매뉴얼은 일반 사용자를 위한 안내입니다. 각 시트에서 무엇을 하고, 어떤 버튼을
어떻게 사용하는지 쉽게 설명합니다.


【Home menu】홈 메뉴
--------------------------------------------------------------------------------

▶ 이 시트는 뭐예요?
  통합문서의 "현관" 같은 곳입니다. 여기서 다른 시트를 열거나 닫을 수 있어요.

▶ 버튼 사용법
  · [시트명] 열기   → 해당 시트가 화면에 나타납니다.
  · [시트명] 닫기   → 해당 시트를 숨깁니다. (닫아도 데이터는 그대로 보관돼요)
  · Stock 열기      → 현재고를 갱신한 뒤 Stock 시트를 엽니다.
  · Stock 닫기      → Stock 시트를 숨깁니다.

  ⚠️ 화면에 보이는 시트가 1개뿐이면 "닫기"를 누를 수 없어요.
     (최소 1개 시트는 항상 보여야 합니다)


【생산일보】
--------------------------------------------------------------------------------

▶ 이 시트는 뭐예요?
  매일 생산한 실적(원지 사용량, 완제품 수량, 작업시간, 비가동 현황 등)을
  기록하는 일일 작업 일지예요.

▶ 무엇을 입력하나요?
  · BK4 셀에 오늘 날짜(작성일)
  · 원지 사용 내역 (직기·봉제 구분, Co, 중량 등)
  · 완제품 가공 내역 (제품명, 설비, 생산량)
  · 작업시간·인력투입
  · 비가동 현황

▶ 주요 버튼
  · 메뉴초기화
    → 시트의 입력 칸을 비웁니다. 새 날짜로 작업 시작할 때 유용해요.


【부자재관리】
--------------------------------------------------------------------------------

▶ 이 시트는 뭐예요?
  부자재(제품별) 입고·사용·재고를 월별로 관리하는 재고장부예요.
  발주처와 제품명을 기준으로, 매월 얼마나 들어왔고, 얼마나 썼고,
  얼마나 남았는지 한눈에 볼 수 있어요.

▶ 버튼 설명 (위에서 아래 순서)

  1. 목록 추가
     → 새 제품(부자재)을 등록할 때 씁니다. 6행짜리 입력 공간이 생겨요.

  2. 재고부족
     → 재고가 부족한 항목을 찾아서 알려줍니다. 발주 전 확인용이에요.

  3. 필터/출력
     → 업체별로 필터를 걸어, 해당 업체 시트만 따로 만들어줍니다.
       출력이나 검토할 때 편해요.

  4. 키워드 검색
     → 제품명이나 발주처 이름을 검색하면, 해당 행으로 화면이 이동해요.

  5. 오늘이동
     → 오늘이 포함된 달의 열로 바로 스크롤해 줍니다.

  6. 다음달 열 추가
     → 새로운 달이 시작되면 이 버튼으로 해당 월의 열을 추가합니다.

  7. 셀보호 해제
     → 시트가 잠겨 있어서 수정이 안 될 때 눌러요. 편집 후 다시 보호할 수 있어요.

  8. 월생산현황
      → 현재 월 기준으로 생산 사용량·재고를 정리해 보여줍니다.


【원단관리】
--------------------------------------------------------------------------------

▶ 이 시트는 뭐예요?
  부자재관리와 비슷하게, 원단(Co·원단명별) 입고·사용·재고를 월별로 관리하는
  재고장부예요.

▶ 버튼 설명
  부자재관리 시트와 같은 역할이에요. 대신 "부자재"가 "원단"으로 바뀐 버전입니다.

  1. 목록 추가          → 새 원단 등록
  2. 재고부족           → 부족한 원단 알림
  3. 필터/출력          → 업체별 원단 시트 출력
  4. 키워드 검색        → 원단명 등 검색
  5. 오늘이동           → 현재 월 열로 이동
  6. 다음달 열 추가     → 새 월 열 추가
  7. 셀보호 해제        → 편집용 잠금 해제
  8. 월생산현황         → 현재 월 원단 사용·재고 현황


【Stock】현재고
--------------------------------------------------------------------------------

▶ 이 시트는 뭐예요?
  부자재관리와 원단관리 시트의 "기말재고(현재고)"를 모아서 보여주는 화면이에요.
  재고 상황만 빠르게 보고 싶을 때 사용합니다.

▶ 사용법
  Home menu에서 [Stock 열기]를 누르면, 현재고가 최신으로 갱신된 뒤
  Stock 시트가 열립니다. [Stock 닫기]로 다시 숨길 수 있어요.


【매뉴얼】
--------------------------------------------------------------------------------

▶ 이 시트는 뭐예요?
  지금 보고 있는 이 매뉴얼 내용이 들어 있는 곳이에요.

▶ 버튼
  상단에 있는 Btn_M1 ~ Btn_M15 버튼을 누르면, 해당 제목(예: 부자재관리, 생산일보 등)
  위치로 화면이 스크롤 이동합니다.


【제품표준사양서】
--------------------------------------------------------------------------------
제품별로 사용하는 원지와 기준소요량 등을 적어 두는 표입니다.
생산일보에서 완제품 관련 수식을 계산할 때 참고합니다.
